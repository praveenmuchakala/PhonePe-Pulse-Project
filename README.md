# PhonePe Pulse Data Visualization
An interactive Power BI dashboard exploring PhonePe Pulse data from 2018 Q1 to 2022 Q4. It includes a 10-metric selector, state map, quarterly trend, growth KPIs, state ranking, and an Insights page.
To view the project, download PhonePe_Pulse_Project.pbix and open it in Power BI Desktop.
